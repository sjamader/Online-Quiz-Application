# 🎯 Online Quiz Application

## 📌 About the Project

The Online Quiz Application is a Java-based desktop application
developed using Java Swing and MySQL.

It provides a platform where users can register, log in, participate
in quizzes, and view their scores. Administrators can manage quizzes
and questions through an admin panel.

## ✨ Features

- User Registration and Login
- Admin Panel
- Create, Edit, and Delete Quizzes
- Multiple-Choice Questions (MCQs)
- Quiz Timer
- Automatic Score Calculation
- MySQL Database Integration
- User-Friendly Graphical Interface

## 🛠️ Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- IntelliJ IDEA
- MySQL Workbench
- Git and GitHub

## ⚙️ Requirements

- Java Development Kit (JDK)
- MySQL Server
- MySQL Connector/J
- IntelliJ IDEA

## 🚀 Installation and Setup

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database.
4. Create the required database and tables.
5. Configure database credentials using environment variables.
6. Add MySQL Connector/J to the project.
7. Run the main Java class.

## 🗄️ Database

Database Name: quizdb

The database stores user information and quiz-related data
according to the application's implementation.

## 🔐 Security

Database passwords and other sensitive credentials should never
be committed to the repository.
